Section 1

1Getting Started

UniFlex Global has two halves: the storefront (the public website your customers shop on) and the admin panel (the back-office where you manage products, orders, and store settings). Both live on the same domain.

The two sides of your site

https://uniflexstore.com/ — public storefront (customers)
https://uniflexstore.com/admin — admin panel (you / staff only)
https://uniflexstore.com/auth/login — sign-in page for both customers and admins

There's only one login page. After signing in, regular customers land on their account page, while staff with an Admin or Super Admin role are able to open /admin from the storefront footer or by navigating there directly.

📌 How to use this guide

Each section below mirrors the menu on the left side of the admin panel (Dashboard, Products, Orders, Customers, Categories, Coupons, Banners, Brand Auths, Analytics, Settings). Section 14 covers the customer-facing storefront, and Section 15 explains the outside services (payments, email, images, AI) that power the store.

First-time setup checklist

  1. Log in with the admin account in Section 2 and confirm the dashboard loads.
  2. Change the default admin password immediately — see Section 2.3.
  3. Review Store Settings (Section 12): store name, support email, tax rate, and shipping rates should reflect your real business.
  4. Check your products (Section 4): the demo catalog has 20 sample products across Electronics, Fashion, Beauty, and Toys — replace or remove these before going live.
  5. Set up your homepage banners (Section 9) and any launch coupons (Section 8).
  6. Confirm payments work by asking your developer to switch Stripe from test keys to live keys (Section 15).
  7. Decide on the AI shopping assistant (Section 13) — turn it on by adding an OpenAI key in Settings, or leave it off.
  8. Remove the demo customer accounts (Alice, Bob, Carol — Section 2.4) once you no longer need them for testing.

2Login & Account Security

Sign in at /auth/login. The same form is used by customers and staff — what you see after logging in depends on your account's role.

2.1 — Your admin login

Store Admin
admin@uniflexstore.com
Admin@1234
ADMIN — full access to /admin
⚠️ Change this password before launch

Admin@1234 is the default password created when the store database was first set up (seeded). Anyone with this document can sign in until it's changed. See Section 2.3 for how to change it.

2.2 — How to sign in

  1. Go to https://uniflexstore.com/auth/login.
  2. Enter the email and password above (or your own staff account once created).
  3. Optionally tick "Keep me signed in for 30 days" — otherwise your session expires after 1 day.
  4. Click Sign in. You'll be taken to your account page — from there, open /admin to reach the back office.

The login page also offers Google, GitHub, and Facebook sign-in buttons. These only work once your developer adds the matching API keys to the site's configuration (Section 15) — until then, use email/password.

2.3 — Changing your password

  1. From the login page, click "Forgot password?".
  2. Enter admin@uniflexstore.com and submit. The store emails a secure reset link to that address (valid for 1 hour).
  3. Open the email, click the reset link, and choose a new password.
📧 This requires email sending to be configured

The reset link is delivered via the store's email service (Resend — see Section 15). If password-reset emails aren't arriving, ask your developer to confirm the RESEND_API_KEY is set up. As a fallback, your developer can update the password directly in the database.

4Products /admin/products

This is where you manage your entire catalog — add new items, edit prices and stock, upload photos, and organize variants like size or color.

The product list

  • Search by name or SKU using the search box.
  • The page shows total product count and supports pagination for large catalogs.
  • Export CSV — downloads your full catalog as a spreadsheet (great for backups or bulk edits in Excel).
  • Import CSV — bulk-create products from a spreadsheet (see below).
  • Add Product — opens the new product form.

Bulk import via CSV /admin/products/import

To add many products at once:

  1. Click Download Template to get a starter CSV with the correct column headers.
  2. Fill in your products in Excel/Google Sheets. Required columns: name, slug, description, price, sku, stock, isActive, isFeatured.
  3. Save as .csv and upload it on the Import page.
  4. Click Import Products. The page reports how many were created and lists any rows that failed (e.g. duplicate SKU).
📝 Note

CSV import creates products without images or variants — add those afterward by editing each product.

Section 5

5Orders /admin/orders

Every purchase made on the storefront appears here. This is your day-to-day fulfillment screen.

Order statuses

StatusMeaning
PENDINGOrder placed and paid, waiting for you to start processing.
PROCESSINGYou're preparing/packing the order.
SHIPPEDPackage handed to the carrier. Setting this status sends the customer a shipping email with tracking info.
DELIVEREDOrder has arrived with the customer.
CANCELLEDOrder cancelled before fulfillment.
REFUNDEDPayment was refunded via Stripe.

Finding orders

Use the status tabs (All / Pending / Processing / Shipped / Delivered / Cancelled / Refunded) to filter the list, or search by customer name, email, or order number.

Order detail page

Clicking an order shows:

  • Items — products, variants, quantities, and prices.
  • Order summary — subtotal, discount (if a coupon was used), shipping, tax, and total.
  • Customer — name, email, phone (or "Guest" + email for guest checkouts).
  • Shipping Address.
  • Tracking — shown once you've marked the order as shipped.
  • Return Request — appears if the customer requested a return, with its status (Pending / Approved / Rejected).

Actions you can take

Update Status

Use the Update Status dropdown to move an order through Pending → Processing → Shipped → Delivered (or to Cancelled).

Mark as Shipped

  1. Choose SHIPPED from the Update Status menu.
  2. A dialog opens — enter the Tracking Number and, if you have one, the Tracking URL (the carrier's tracking page).
  3. Click Confirm Shipment. The customer automatically receives a "your order has shipped" email with this tracking info.

Issue Refund

⚠️ This cannot be undone

For paid orders, an Issue Refund button appears. Clicking it and confirming will refund the full payment through Stripe, mark the order as REFUNDED, and notify the customer by email. Use this for cancellations or approved returns.

Section 13

13AI Shopping Assistant

A floating chat widget on the storefront that helps customers shop — like having a knowledgeable sales associate available 24/7.

What it can do for customers

CategoryCapability
DiscoverySearch/recommend products, answer product questions, check if a brand is "Authorized Reseller", explain store policies (shipping, returns, etc.)
CartView cart, add/remove items, change quantities, clear the cart
CouponsApply a discount code to the cart
CheckoutHand the customer a direct link to checkout
OrdersList past orders, check an order's status, request to cancel an order or start a return

Built-in safeguards

  • Confirmation cards — for anything that changes the cart or an order (adding items, applying a coupon, cancelling an order, etc.), the assistant shows a card with the exact change and price impact. Nothing happens until the customer clicks Confirm.
  • Sign-in required for cart/order actions — guests can browse and ask questions, but must be logged in to act on their cart or orders.
  • Sanity limits — max 10 units per action, and a warning if a cart total exceeds $5,000.
  • The assistant is hidden on the admin panel, login pages, and checkout — it only appears for shoppers browsing the store.

Turning it on/off

Go to Admin → Settings → AI Assistant tab (Section 12) and add or remove an OpenAI API key. No key = the widget doesn't appear at all, so there's no cost or risk if you'd rather not offer it.

Returns & cancellations

From their order detail page, signed-in customers can request to cancel an order (if it hasn't shipped) or request a return. These requests appear on the corresponding order in Admin → Orders (Section 5) for you to review and act on (e.g. issue a refund).

Cookie consent

First-time visitors see a cookie consent banner (GDPR/CCPA-style) at the bottom of the screen, linking to the Cookie Policy page.

Section 15

15Services & Credentials

UniFlex Global relies on a few outside services. Most are configured by your developer on the hosting server and don't need day-to-day attention — this table is a reference for what each one does and where to manage it if needed.

ServiceUsed forWhere it's managed
Database (Neon / PostgreSQL) Stores all products, orders, customers, and settings. Server configuration — developer-managed.
Stripe Payment processing and refunds. dashboard.stripe.com for transaction history/disputes. API keys live in the server configuration — ask your developer to switch from test to live keys before launch.
Resend Transactional emails — verification, password reset, order confirmation, shipping updates. resend.com dashboard for delivery logs. API key in server configuration.
Cloudinary Hosts and optimizes every image you upload (products, banners, categories, certificates, logos). cloudinary.com/console for storage usage. Uploads happen directly from the admin panel — no manual steps needed.
OpenAI Powers the AI shopping assistant (Section 13). Self-service: Admin → Settings → AI Assistant tab (Section 12). Get a key at platform.openai.com/api-keys.
🔑 About API keys

Most of the keys above (Stripe, Resend, Cloudinary, the database connection) are stored in a server configuration file that is not part of this guide for security reasons — if a key is ever compromised, anyone holding it could access payments, email, or customer data. If you need to view or rotate one of these keys, ask your developer. The only key you can manage yourself day-to-day is the OpenAI key for the AI assistant, via the Settings page.
